* ideas

1. For every file, module, function, type, create a recursive rust enum to label all of it.
   this assigns a unique number to each composable type indirectly via the enum system.
1.2. search those enums in rust.
   write code to reason about those enums.
1.3. yaml or lisp or json form
   convert that to a jq query.
